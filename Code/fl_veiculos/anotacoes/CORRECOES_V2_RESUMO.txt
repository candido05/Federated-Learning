================================================================================
PARÂMETROS NOVOS QUE FUNCIONAM (MANTER!)
================================================================================

✅ max_delta_step: 1 (XGBoost)
   - Específico para classes desbalanceadas
   - Limita máximo step em cada árvore
   - Ajuda a evitar que classe majoritária domine

✅ boost_from_average: True (LightGBM)
   - Inicializa modelo com média das classes
   - Melhor que inicializar em zero para desbalanceamento

✅ num_leaves: 31 (LightGBM)
   - Reduzir de 255 para 31 ajuda a evitar overfitting
   - 31 é suficiente para capturar padrões

✅ depth: 5 (CatBoost)
   - Baseline era 6, reduzir para 5 ajuda
   - Menos overfitting sem perder capacidade


================================================================================
LIÇÕES APRENDIDAS
================================================================================

1. ❌ NÃO aumentar Learning Rate em FL com boosting!
   - FL já tem convergência mais lenta
   - LR 0.05 causa oscilação/instabilidade
   - Sweet spot: 0.02-0.03 para FL

2. ❌ Regularização excessiva é PIOR que overfitting!
   - subsample 0.7 × colsample 0.7 = 49% dos dados
   - Resultado: Modelo muito simples, não aprende padrões
   - Baseline (0.8 × 0.8 = 64%) é melhor

3. ✅ Parâmetros específicos para desbalanceamento FUNCIONAM!
   - max_delta_step (XGBoost)
   - boost_from_average (LightGBM)
   - Manter SEMPRE ativados

4. ⚠️ Testar incrementalmente é ESSENCIAL!
   - Mudar tudo de uma vez mascara o que funciona
   - Melhor: Testar uma mudança por vez

5. ✅ Class weights + curriculum learning já estavam funcionando!
   - Infraestrutura avançada já implementada
   - O problema era APENAS os hiperparâmetros básicos

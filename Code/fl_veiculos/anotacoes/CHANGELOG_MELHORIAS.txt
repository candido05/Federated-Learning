================================================================================
OBSERVAÇÕES E LIÇÕES APRENDIDAS
================================================================================

1. ✅ SMOTE não funciona bem neste dataset (tentativa anterior falhada)
   - Alternativa: class weights funcionam melhor para tree-based models

2. ✅ Infraestrutura avançada JÁ estava implementada!
   - Class weights, early stopping, curriculum learning
   - Apenas precisou OTIMIZAR hiperparâmetros

3. ❌ Learning Rate 0.05 é MUITO ALTO para FL com boosting!
   - Causou underfitting severo (acurácia -10%)
   - Correção: 0.03 é o sweet spot
   - Lição: FL precisa de LR menor que centralized learning

4. ❌ Regularização excessiva piora mais que overfitting!
   - subsample 0.7 × colsample 0.7 = 49% de dados
   - min_data_in_leaf 50 remove muitos padrões
   - Correção: Voltar para 0.8 × 0.8 = 64% de dados

5. ✅ max_delta_step e boost_from_average ajudam!
   - Parâmetros específicos para desbalanceamento
   - Manter ativados mesmo com correções

3. ✅ Hiperparâmetros antigos causavam overfitting após round 12-15
   - Learning rate muito baixo (0.01-0.02)
   - Árvores muito profundas (depth 6)
   - Solução: Aumentar LR para 0.05, reduzir depth

4. ✅ max_delta_step (XGBoost) e boost_from_average (LightGBM)
   - Parâmetros específicos para classes desbalanceadas
   - Antes não estavam sendo usados

5. ⚠️ IMPORTANTE: use_stable_params=True no main.py
   - Sem isso, os hiperparâmetros otimizados não são aplicados!

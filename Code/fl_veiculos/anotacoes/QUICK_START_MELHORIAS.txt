================================================================================
MELHORIAS IMPLEMENTADAS (ATIVAS)
================================================================================

✅ 1. CLASS WEIGHTS (Balanceamento automático)
   - Penaliza erros em classes minoritárias
   - Max weight: 5.0 (evita instabilidade)
   - Ativo via: use_class_weights=True no main.py

✅ 2. EARLY STOPPING LOCAL
   - Para treinamento se não melhorar por 5 rounds
   - Economiza ~20-40% do tempo
   - Ativo via: use_early_stopping=True no main.py

✅ 3. HIPERPARÂMETROS OTIMIZADOS
   - XGBoost: max_depth=4, eta=0.05, max_delta_step=1
   - LightGBM: min_data_in_leaf=50, boost_from_average=True
   - CatBoost: depth=5, learning_rate=0.05, l2_leaf_reg=5.0
   - Ativo via: use_stable_params=True no main.py

✅ 4. CURRICULUM LEARNING
   - Ajusta pesos de classes progressivamente por round
   - Warmup de 5 rounds antes de aplicar pesos máximos
   - Ativo via: use_curriculum=True no main.py

✅ 5. DIVERSITY AGGREGATION
   - Agrega modelos ponderando por entropia de classes
   - Clientes com classes mais balanceadas têm mais peso
   - Ativo via: diversity_aggregation=True no main.py


================================================================================
COMO EXECUTAR OS EXPERIMENTOS
================================================================================

OPÇÃO 1: Executar TODOS os algoritmos e estratégias (RECOMENDADO)
-------------------------------------------------------------------
python main.py --algorithm all --strategy both

Isso executará 6 experimentos:
1. XGBoost Cyclic
2. XGBoost Bagging
3. LightGBM Cyclic
4. LightGBM Bagging
5. CatBoost Cyclic
6. CatBoost Bagging

Tempo estimado: ~6-10 minutos (com early stopping)


OPÇÃO 2: Executar algoritmo específico
-------------------------------------------------------------------
# XGBoost apenas
python main.py --algorithm xgboost --strategy both

# LightGBM apenas
python main.py --algorithm lightgbm --strategy both

# CatBoost apenas
python main.py --algorithm catboost --strategy both


OPÇÃO 3: Executar experimento único (para testes rápidos)
-------------------------------------------------------------------
# XGBoost Cyclic (mais rápido)
python main.py --algorithm xgboost --strategy cyclic

# LightGBM Bagging (melhor baseline)
python main.py --algorithm lightgbm --strategy bagging


OPÇÃO 4: Customizar parâmetros
-------------------------------------------------------------------
# Reduzir rounds para teste rápido
python main.py --algorithm xgboost --strategy cyclic --num-rounds 10

# Alterar número de clientes
python main.py --algorithm lightgbm --strategy bagging --num-clients 5

# Testar sem balanceamento (baseline)
python main.py --algorithm catboost --strategy cyclic --balance None

================================================================================
TROUBLESHOOTING
================================================================================

ERRO: "OOM (Out of Memory)"
---------------------------
Solução: Reduzir número de clientes
python main.py --algorithm xgboost --strategy cyclic --num-clients 5


ERRO: "No module named 'scipy'"
---------------------------
Solução: Instalar dependências
pip install scipy scikit-learn


ERRO: Experimento muito lento
---------------------------
Verificar se early stopping está ativo:
grep "use_early_stopping" main.py
# Deve mostrar: "use_early_stopping": True


ERRO: Balanced Accuracy não melhora
---------------------------
Verificar se stable params está ativo:
grep "use_stable_params" main.py
# Deve mostrar: "use_stable_params": True


ERRO: Class weights não aparecem no log
---------------------------
Verificar configuração:
grep "use_class_weights" main.py
# Deve mostrar: "use_class_weights": True
